# 山海有形 · Shanhai Youxing

> 字裡行間 · 一紙之島　　寫木為舟 · 寫水成淵
>
> *Where Mountains and Seas Take Form.*
>
> **「寫意」系列 · 第一部**

> 鳥棲於山，是為島。一張紙落在海上，紙上的字活了。你是其中的一個「人」，赤手空拳。

一個**由漢字構成的 2D 生存與探索沙盒**。山就是「山」字，水就是「水」字，樹是「木」，林是「林」，虎是「虎」。收集、製作、砌磚，撐過一夜又一夜；探索小島上的八處地方，讀完它們留下的話；膽氣夠了，就造一艘船（孤帆或方舟），開出這張紙。

純瀏覽器單頁遊戲，零依賴，雙擊就能玩。預設繁體（台灣用語），起始頁與暫停面板可切換成**簡體中文**（只換顯示的字，存檔照用）。

本作是**「寫意」遊戲系列**的第一部。「寫意」是系列名，之後可能再出系列的其他遊戲；系列各作的內部識別名都以 `xieyi` 起頭。

## 立刻開玩

- **線上**：https://claude.ai/artifact/AaW9h52xsssPP5beWgBErX （拿到連結的人都能開）
- **本機**：下載或 clone 這個 repository，**雙擊 `index.html`** 就能玩。也可以起一個本機伺服器：

  ```bash
  python3 -m http.server 8123     # 然後開 http://127.0.0.1:8123/
  ```

- 起始頁有**八格存檔**（v0.8 起，一排四格），每格寫著島號、難度、第幾日、膽氣第幾重、死過幾次、存檔時刻。點一格選它：「繼續」讀那一格；選難度、輸入**世界種子**（同一個種子長出同一座島），按「落筆」把新島寫進那一格（格裡有存檔會先問一聲，再按一次才覆蓋）；「刪」也要按兩次。回車等於選著的格有存檔就繼續、沒有就落筆。
- 網址參數：`?seed=123` 指定種子；`?slot=2` 選第二格；`?autostart=1` 跳過起始頁。
- **存檔**在瀏覽器本地，每二十秒自動存一次，切到背景或關掉頁面也會存。渡海「再來一座島」會清掉那一格，膽氣帶到下一座島。
- 書法字體「霞鶩文楷 TC」從 Google Fonts 線上載入；離線時退回系統的標楷體，照常能玩。
- **桌面版**（v0.5.7，試做中）：用 Electron 包成 Windows／Linux 的執行檔，為上 Steam 做準備。每次合進 `main` 由 GitHub Actions 自動打包，在 Actions 頁「桌面版（Electron）」的 Artifacts 下載；下載與打包見 [`desktop/README.md`](desktop/README.md)。

### 系統需求（v0.6.4 估計）

遊戲是單執行緒的 Canvas 2D，吃 CPU 為主；瀏覽器開著硬體加速時，放大、疊圖這些填色工作交給顯示晶片。實測環境是無頭 Chromium、**沒有顯示晶片**（全靠 CPU 軟體繪圖）、Intel Xeon 2.1 GHz：夜裡八盞燈加一片霧加下雨，畫一幀 1280×720 約 2–2.5 毫秒、1920×1080 約 4 毫秒，遊戲邏輯不到 1 毫秒，JS 記憶體約 10 MB。下面是照這個推估的，還沒有在實機上逐台量過。

| | 最低 | 推薦 |
| --- | --- | --- |
| CPU | 雙核 2 GHz（約 2013 年後的 Intel Core i3、AMD A 系列） | 四核 2.5 GHz 以上（Intel Core i5 第八代、AMD Ryzen 5 2000 系列、Apple M1 或更新） |
| 記憶體 | 4 GB | 8 GB |
| 顯示 | 有硬體加速的內顯（Intel HD 4000 以上） | Intel UHD 620、AMD Vega 8 或更好 |
| 畫面 | 1280×720，30 fps 以上 | 1920×1080，60 fps；4K 螢幕（畫面放大兩倍）用推薦配置 |
| 瀏覽器 | 近三年的 Chrome、Edge、Firefox、Safari | 同左 |
| 桌面版 | 另需約 300 MB 磁碟，多吃 200–300 MB 記憶體（Electron 自帶 Chromium） | 同左 |

## 遊戲介紹

**一紙之島。** 每座島都由種子程式生成：海、灘、沙、礫、石、山、雪、草、田、木、林、森、竹、棉、麻、果，還有山裡的煤層與鐵礦脈。地圖只畫你走過的地方。潮水一天漲落一次，退潮時才露出一條沙路，通往島外小嶼上的燈。

**群島。**（v0.7）整張紙 1600×1600 格（v0.9.5 從 2500×2500 縮小）。本島比從前大四成五；四面海上是**大陸與島**（v0.8.27；v0.9.5 起每一局都是，舊存檔也搬了過來）：整張紙約四成是陸地，分五種地域——**大漠**（沙丘、綠洲的池水與椰棗；白天烈日、夜裡寒）、**火山**（熔岩、岩地、黑曜石脈、溫泉）、**川原**（河湖縱橫、水是淡的、林木茂密）、**雪原**（冰雪寒地，山腹有洞窟，窟邊煤鐵多，山腳有溫泉）、**青野**（尋常的山林田野）；開闊的海上另散著孤嶼。膽氣八重造了船就能去。

**紙的四方。**（v0.8.4）不管哪個島號，紙的四方都一定有這幾處，是魔王與神獸住的地方：東邊**龍淵**（東海青龍盤著的深海，方圓四十九格沒有一塊地）與**洞庭**（一圈礁圍著的淡水湖，四個口子給船進出）；西邊**虎嶺**（白石嶙峋，嶺上有鐵）與**桑林**（林心一塊草地）；南邊**丹穴**（滿地紅花）與**青丘**（高原草野，島邊一片澤）；北邊**玄洲**（林深，有淡水的潭）；西北一座**不周山**（方圓一百二十格的山地，一圈大山圍著盆地，東南缺一口）。陸的島心方圓三十八格都走得上去。第一次到一處，膽氣 +10；地名寫在狀態列與大地圖上。

**活下去。** 命、飽、暖、力、愜意五條數值，加上一條代表成長的「膽氣」。夜裡冷，獸會出來；餓了要吃，累了要歇，悶了要找點事做。

**製作與建造。** 五十八條配方，分成居所、工具、神兵、衣甲、燈火、漁船、食藥、材料八類：磚、門、床、灶、櫃、稻草人、棧；石器、鋼具、鎢鋼具；布、鐵、鎢鋼三等衣甲；火把、蠟燭、燈、燈帽；漁網、魚梁、竹筏、孤帆、方舟；藥、果酒、丹；火島的黑曜石磨成曜刃。

**夜與獸。** 虎、豹、狼、蛇、蜘蛛、蟾蜍，各有各的脾氣。第十三夜起，穿磚、怕光的「魄」夜行：磚擋得住獸，擋不住魄，只有光才行：手上的光逼得退，地上的燈才燒得死；夜越深魄越多越快，還會撲上來吹熄你手裡的火把。例外是**小屋**：磚與門圍起的小空間，裡面不生生靈，獸進不來；夠小的話連魄也進不來，多小才算看難度，困難的魄什麼磚都擋不住。

**天氣。** 雨不分晝夜，會澆壞屋外的燈（機率看難度）；附近不時起一片霧障，不帶扇子硬闖，五樣數值各掉一成。霧會慢慢飄，躲著燈火，也躲著手裡有光的你；沒帶光的人，會被霧追上。

**海。** 海上有吞吐霧障、會撞船的「蜃」。殺虎豹狼偶爾得到牠們的首骨，放在船頭，蜃就不敢近；船毀了，只有六十息游上岸。

**成長。** 膽氣一圈一重：八重造船，十六重五件衣甲穿齊（其中至少一件鎢鋼）便是「山海衣」（衣上浮出《山海經》的獸紋），卅一重可鑄三件神兵：陸上的撼地之鎚「九閽鳴雷」，海上的「燭龍焚溟」，射天上之物的「青冥落羽」（要畢方羽）。

**夥伴與探索。** 山間的鷹可以用魚馴服，替你打獸。洞裡的龍往東海去了，只留下一片青鱗（v0.8）：本島往東約三百八十格（v0.9.5 前約六百格）的深海上盤著**東海青龍**，斃蜃得蜃殘體（一或二塊），九塊加海水瓶三、淡水瓶一（「熬」底下四點）在火旺的鼎裡熬成蜃珠（八成三的機會成，成了四個空瓶退回；不成鼎裡炸了、瓶都碎，殘體退回，困難只退八塊），帶去求教，牠教你行船的水性：孤帆、方舟從此自己慢慢回命（兩日回滿），落了水也撐得久些（倒數慢四分之一，游泳的苦頭也減半）。右上角膽氣環外面隔一點空的那圈**魂環**，龍魂那一段多一顆十字星（v0.8.21 起魂環那一段要斃了修蛇才亮；求教給的是十字星）；魂環上方自成一排的四顆珠是玄武的四卷經（v0.8.22）。斃了第一頭蜃，見聞錄裡多一頁**魔物誌**：十二隻大型魔物一隻一張卡，遇過的才寫得出來，沒遇過的蓋著、只留一句線索。島上八處地方，各留了一段話。

**名字。** 山就是「山」，水就是「水」，象形字本來就有形，所以叫「山海有形」。「寫意」原是最早「組字造詞」版本的名字，現在是整個系列的名字，《山海有形》是「寫意」系列第一部；改名的來由寫在 [`docs/SPEC.md`](docs/SPEC.md) §2.2。

### 畫面

- **左上**：紅印「山海有形」；五條直條是命（紅）、飽（黃）、暖（橙）、力（綠）、愜意（藍），條上有 25%、50%、75% 三道尺標。下面是**身上**：上排內襯、褲、甲，下排盔、靴、燈帽，每格寫著還能穿幾日；再下面四行：傷害獲取、移動速度、傷害輸出、現今蟲獸傷害輸出。
- **左下**：山海衣的滑動開關。
- **右上**：狀態列（第幾日、時辰、日月、下雨時的「雨」字、第幾夜與「魄夜」、潮汐、所在地名、座標、難度）；圓形小地圖，外圈金色弧是這一重膽氣的進度；「暫停」與「放大地圖」兩個鈕。
- **右側**：夥伴面板，馴了的鷹一隻一欄，兩條直條是命與力。
- **下方**：提示列（面前是什麼、能做什麼）；左邊六格**具欄**放工具（有耐久的工具外面包一圈耐久環，剩多少畫多少，低於四分之一轉紅），右邊**囊**分「食」「物」兩段，共用十六格。
- **畫面邊緣**：掉血泛紅、中毒泛綠、神志不清泛藍。

### 第一天怎麼過

1. **取材料**：面向樹按 `E` 得木，面向草得草，土得土；碎石地「礫」得石子，石地得石；野棉、野麻得棉、麻；果樹得果，可以直接吃。
2. **磨一把工具**：按 `C`，在「工具」類選磨礪（石一、石子一、木一），挑石劍防身或石鎬鑿山。工具自動放進具欄：武器（刀劍）在「武」段、農具（鎬鋤斧）在「農」段，`P` 換武器、`O` 換農具。
3. **做火把**：石子一、草三、木二，一次四根。夜裡拿在手上才亮，虎豹怕光。
4. **蓋屋**：磚＝土二草一，一次兩塊；門＝木三。砌一圈磚，留一扇門，獸就進不來。磚門窗灶櫃鼎床燈可以直接放在草、花、田、路上（一半機會順手收到底下的草、花或一捧土），上面站著生靈就放不下。
5. **床與灶**：床＝棉六木二，夜裡面向它按 `R` 睡到天明，睡一覺力全回、愜意 +20。灶＝石六，面向它按 `F` 開灶，在界面裡添柴，火旺時把魚、肉烤熟（生吃傷身）。
6. **紮一把扇子**：草四木一。第二天起可能起霧障，帶著它就不怕。
7. **第十三夜前**：備好火把或蠟燭（棉一肉一做兩根；棉一油脂一做三根；油脂裝在麻布包裡，麻布二、麻一縫一個，一包八份），或做一頂燈帽（麻布二蠟燭一）戴在頭上。燈（石二火把一）放在屋裡長明不滅，放在屋外會被雨澆壞。人跨得過燈，獸過不去，磚上嵌一盞燈就是只有你能走的門。
8. **去探索**：找到「塔」登上去，全島都會畫到地圖上；面向村口的門按 `E` 可以問路。

### 六條數值與膽氣

五條數值不到五成，那條的外框每兩秒閃一下黃；不到四分之一每秒閃一下紅，並彈窗提醒一次（回到五成以上後才會再提醒；困難只閃不提醒）。

**膽氣**是成長：採集天然的東西、製作、捉魚、擊敗野獸、讀地標都會長；右上小地圖一圈一重，越高命、力、愜意回得越快（十重兩倍）。**廿二重起只從斃敵對的生靈得來**，製作、採集、讀碑都不再長；斃敵對生靈的膽氣白日只有八成、夜裡加半成（鹿與龜不算敵對），夜裡出門才長得快。升一重要的點數一重比一重多：20、24、29、34、39……八重共 300、十重共 437。斃敵的基礎值：虎 30、豹狼 15、蛇 7.5、蛛鷹 5、蜃 40（白日八成、夜裡加半成）；所有膽氣來源再乘難度加成：簡單 ×1.4、一般 ×1.25、困難 ×1.15。

- **八重**：可以造船：孤帆與方舟。
- **十六重**：五件衣甲穿齊、其中至少一件鎢鋼護具，便是山海衣（見下）。
- **卅一重**：可以鑄神兵九閽鳴雷、燭龍焚溟、青冥落羽。過了卅一重，膽氣三日一減，不低於卅一重；身上帶著神兵（幾件也只算一重）則看難度：簡單四日一減到廿八重、一般三日到廿七重、困難二日到廿六重，困難另慢慢掉力。
- **死亡**：膽氣減六成，留四成。

所有數值都算到小數點後四位（v0.6.2），畫面上看到的一律是整數（v0.6.8）：一再出現的數（傷害、回復、膽氣）每回四捨五入，零頭攢著，攢過半點就多顯示一點、多的下回扣回來。例如每下 53.13 的傷害顯示成 −53 −53 −53 −53 −54……，看到的加起來跟真的差不到半點；獸「還有多少命」照看到的傷害算。

### 天氣：雨與霧障

- **雨**：白天黑夜都會下，一場四分之一到一日，停後一到四日再來，狀態列會多一個「雨」字。屋外的燈每盞每息有一點機會（簡單 1/4500、一般 1/2500、困難 1/800）被雨澆壞，澆壞就沒了；四面有磚圍起來的屋裡（門也算磚）不怕。
- **霧障**：第二日起，每天兩次、每次四分之一的機會，附近的陸地上起一片霧，一日後自己散。霧是一塊連續的形：面積十八格上下，可圓可方、扁圓斜正都有，邊緣還會慢慢起伏，形狀一直在變；蓋到一格超過 5% 那格就算霧，最多算三十格（v0.6.4）。霧順著風連續地飄（每息約六分之一格），躲著燈火與手上的光；爬山渡海都不回頭（v0.6.5）。圍起來、裡面不超過四十五格的屋子，霧進不去：碰上了就拐開繞過去，形狀變了、面積不變。走進去會跳出彈窗：
  - 有扇子：選「用一把扇子吹散」（整片散，花一把），或「不用，硬闖」。
  - 沒有扇子，或選了不用：命、飽、暖、力、愜意各掉當前的一成（不會致命）。
  - 同一片霧裡走動不再問，走出去再進來才再問。扇子選中按 `V` 也能先吹散三格內的霧。
- **潮汐**：退潮時灘是沙，漲潮時是水；困在灘上可以涉水走到相鄰的灘。船、魚梁不能放在灘上（退潮會擱淺）；漁網可以（退潮曬著，魚慢三成）；棧可以，搭了漲潮也走得過。

幾個實作選擇：

- **世界只存差異。** 底稿由 `(x, y, seed)` 雜湊決定，可複現；玩家改動的格子放在稀疏表裡，存檔只有幾 KB。
- **潮汐是一種地貌。** 潮道的底稿是「灘」，讀取時按時辰解釋為沙或水。
- **擋路靠格子本身。** 一圈磚加一扇門就是避難所，不需要另外判斷「封閉」。雨澆燈時判斷「屋裡」才用到圍不圍得住。
- **磚擋獸、光擋魄。** 兩種威脅要兩套準備。
- **種子與真隨機分開。** 島長什麼樣走種子；天氣、霧障、馴鷹、煉丹、龜卜走真隨機，同一座島每次玩都不同。

**靈感來源與差異**：Minecraft（收集、製作、避難所、夜裡的怪）、Don't Starve（飢餓、體溫、日夜）、Team9 的《文字遊戲》都在前面。本作的不同在於開放世界的生存循環、世界與物品都是漢字、介面是宣紙與楷書、地圖是走出來的、故事靠走到那裡讀到。繁體的構形留在字裡：島＝鳥＋山，泉＝白＋水。

**路線圖**：農事（田裡種果棉麻、節氣）；渡海之後的島各不相同（林密、潮汐、寒山）；更多天氣（雷、雪、風）；村民。
